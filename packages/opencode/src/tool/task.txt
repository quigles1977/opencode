Launch agent for complex multi-step tasks.

Agent types: {agents}

When to use:
- Slash commands: Task(description="desc", prompt="/command args")

When NOT to use:
- Reading specific files → Use Read/Glob
- Searching for class/function → Use Glob
- Searching in 2-3 files → Use Read

Notes:
- Launch multiple agents in parallel when possible
- Agent returns single message (not visible to user) - summarize for user
- Agents are stateless - provide detailed task description
- Specify if agent should write code or just research

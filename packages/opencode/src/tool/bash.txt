Executes bash commands in persistent shell.

Usage:
- Quote paths with spaces: cd "/path with spaces/file.txt"
- Use List to verify parent dirs before mkdir/touch
- Avoid: find, grep, cat, head, tail, ls → Use Grep/Glob/Read/List tools
- Chain commands with && or ;
- Use absolute paths, avoid cd
- Timeout: 120s default, 600s max


# Git Commits

Process:
1. Run in parallel: git status, git diff, git log -1
2. Draft message in <commit_analysis>: files changed, nature (feature/fix/refactor), purpose, impact
3. Stage files, create commit
4. If hook modifies files, amend once

Rules:
- Never: update config, push, use -i flags, commit irrelevant files
- Message must be specific (avoid "Update" without context)

# Pull Requests

Process:
1. Run in parallel: git status, git diff, git log, git diff main...HEAD
2. Draft in <pr_analysis>: all commits since main, nature, purpose, 1-2 bullet summary
3. Push if needed, create PR: gh pr create --title "title" --body "$(cat <<'EOF'\n## Summary\n- points\nEOF\n)"

Rules: Never update config. Return PR URL.

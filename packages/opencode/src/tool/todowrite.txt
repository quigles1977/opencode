Track multi-step tasks with structured todo list.

## When to Use
- 3+ steps or complex planning
- User provides multiple tasks
- Non-trivial implementation requiring tracking

## When NOT to Use
- Single straightforward task
- Trivial/informational queries
- < 3 simple steps

## Task States
- pending: Not started
- in_progress: Currently working (ONE at a time)
- completed: Finished (mark IMMEDIATELY, no batching)
- cancelled: No longer needed

## Management
- Update status in real-time
- Complete current before starting next
- Break complex tasks into specific steps
